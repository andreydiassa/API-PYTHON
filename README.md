# API-PYTHON

Uma API REST simples desenvolvida em Python utilizando o FastAPI com o objetivo de praticar conceitos de desenvolvimento backend, métodos HTTP e operações CRUD.

O projeto foi criado para aprofundar conhecimentos em APIs REST e na construção de aplicações utilizando Python, trabalhando com armazenamento temporário em memória para simplificar a estrutura da aplicação.

Funcionalidades:
Cadastro de produtos
Listagem de produtos
Atualização de produtos
Remoção de produtos
Validação de dados
Documentação automática com Swagger Docs

Métodos HTTP Utilizados:
GET
POST	
PUT	
DELETE	

Tecnologias Utilizadas:
Python
FastAPI
Visual Studio Code
Swagger Docs
JSON

A aplicação utiliza:
operações CRUD
validação automática com Pydantic
rotas REST
armazenamento temporário em memória
